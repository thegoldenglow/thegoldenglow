# 🚀 Quick Setup: Channel Verification

## Steps

1. Make bot admin in `@GoldenGlowGlobal`
2. Set env vars: `TELEGRAM_REQUIRED_CHANNEL`, optional `TELEGRAM_SKIP_MEMBERSHIP_CHECK`
3. Deploy to Netlify (auto)
4. Reset webhook: `/telegram/set-final-clean-webhook`
5. Test with a non-member → join → verify
